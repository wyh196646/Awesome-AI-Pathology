无需在标题出现 `pathology`。官方区间入口分别为

每页 cursor、数量、查询 URL，以及失败的 arXiv 完整查询 URL 均存入 JSON 审计。

为完成较慢的分页请求，使用临时辅助程序预取并验证独立 API 页，再由原脚本读取
缓存完成检查。bioRxiv 检索过程中宣告总数由 5,185 增至 5,189；最终 5,189 行
均为不同的 DOI、版本、日期组合，无重复行。medRxiv 的 1,369 行也全部唯一。
平台索引可能延迟变化，下一轮继续保留 14 天重叠窗口；这些核对不构成完整覆盖
所有相关研究的保证。
